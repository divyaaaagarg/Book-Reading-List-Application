# Book Reading List Application

A responsive reading tracker that lets users add books, mark them as read or unread, filter the list, and remove entries. The list is saved in the browser using local storage.

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)
- Browser Local Storage

## Features
- Add a book title and author.
- Mark books as read or unread.
- Filter all, unread, and completed books.
- Remove books from the list.
- Persistent storage in the current browser.
- Responsive layout and helpful empty states.

## Run locally
Open `index.html` in a modern browser, or start a local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
